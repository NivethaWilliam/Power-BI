
# 📊 Power BI Assignment 2: DAX & Data Visualization

## 📌 Project Overview

This project focuses on using Microsoft Power BI to perform data analysis with DAX (Data Analysis Expressions) and create meaningful data visualizations. It demonstrates how calculated measures, analytical expressions, and interactive reports can transform raw data into useful business insights.

## 🎯 Project Objectives

- Understand and apply DAX functions in Power BI.
- Create measures and calculated columns where required.
- Perform calculations to analyze business performance.
- Develop interactive reports and dashboards.
- Present key metrics using appropriate visualizations.
- Improve data interpretation and analytical decision-making.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling
- Data Visualization
- Interactive Reports and Dashboards

## 📐 DAX Concepts

The assignment focuses on DAX concepts such as:

- **Measures:** Calculate aggregated values dynamically based on report filters.
- **Calculated Columns:** Create row-level calculations within tables.
- **Aggregation Functions:** Perform calculations such as SUM, AVERAGE, COUNT, and DISTINCTCOUNT where applicable.
- **Logical Functions:** Apply conditional logic using functions such as IF and SWITCH.
- **Filter Context:** Understand how slicers, filters, and visual interactions affect calculations.
- **Time Intelligence:** Apply date-based calculations when supported by the dataset.

## 📊 Data Visualization

Power BI visualizations help present analytical findings in an easy-to-understand format.

Potential visualization techniques include:

- KPI cards for key performance indicators.
- Bar and column charts for comparisons.
- Line charts for trends over time.
- Pie and donut charts for category distributions.
- Tables and matrices for detailed analysis.
- Slicers and filters for interactive exploration.

*The specific visuals and DAX functions used depend on the contents of the Power BI report.*
